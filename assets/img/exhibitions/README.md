# 전시 사진 넣는 곳

projects.html 의 각 칸이 아래 파일명을 **이미 가리키고 있습니다.**
같은 이름으로 이 폴더에 넣기만 하면 그 칸이 바로 채워집니다.
아직 없는 파일은 자동으로 자리표시 이미지(사진 준비 중)로 보입니다.

| 파일명 | 페이지 위치 |
|---|---|
| `busan-2025.jpg`            | 부산 일러스트레이션 페어(2025) |
| `seongsu-2025.jpg`          | 성수동 언더스탠드 애비뉴 팝업(2025) |
| `seongsu-2025-invite-1.jpg` | └ 초대장1 |
| `seongsu-2025-invite-2.jpg` | └ 초대장2 |
| `squareone-2025.jpg`        | 스퀘어원 팝업(2025) |

## 알아두면 좋은 것

- **확장자가 다르면** (png 등) projects.html 의 해당 `<img src>` 도 같이 고쳐야 합니다.
- **비율은 맞추지 않아도 됩니다.** 사진 원래 비율 그대로 놓이고 모서리만 둥글게 처리됩니다.
- 클릭하면 확대해서 보는 기능이 붙어 있습니다. 확대 화면도 같은 파일을 쓰므로
  **긴 변 1600px 안팎**이면 충분히 선명합니다. 인쇄용 원본은 너무 큽니다.
  (크게 올리셔도 됩니다 — 웹용으로 줄여서 넣어드립니다)
