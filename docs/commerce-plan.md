# 판매 개시 준비 — 결제·환불·회원 정책 설계

워크북 판매를 시작하려면 약관 제10조(결제·환불)를 채우고 구매 페이지를 만들어야 합니다.
이 문서는 **무엇을 먼저 정해야 하고, 각 선택이 무엇을 바꾸는지**를 정리한 것입니다.

> 이 문서는 실무 정리이며 법률 자문이 아닙니다. 판매 개시 전 전문가 검토를 권장합니다.

---

## 0. 현재 상태

| 항목 | 상태 |
|---|---|
| 판매 | 미개시 (랜딩 + 이메일 수집만) |
| 이용약관 제10조 | "구매 페이지에 별도 고지"로 비워둠 |
| 결제 백엔드 | 없음 (`api/subscribe.js` 하나뿐) |
| 통신판매업 신고 | 미신고 |
| 가격 ₩16,900 | 임시값 |

## 1. 먼저 정해야 할 네 가지

아래 네 가지가 나머지를 전부 결정합니다. 이것부터 확정해 주세요.

### ① 워크북의 형태

| 선택지 | 청약철회 | 추가로 필요한 것 |
|---|---|---|
| **PDF 다운로드** | 조건 충족 시 제한 가능 (→ 3장) | 다운로드 링크 발급·만료 처리 |
| **실물 인쇄본** | 수령 후 7일 원칙 적용 | 재고·배송·반품 처리, 배송비 정책 |
| **PDF + 실물 세트** | 각각 따로 적용 | 위 둘 다 |

> 형태에 따라 환불 정책이 정반대로 갑니다. 이게 가장 먼저입니다.

### ② 회원제 여부

| 선택지 | 장점 | 단점 |
|---|---|---|
| **비회원 구매 (권장)** | 가입 마찰 없음, 개인정보 최소 수집, 탈퇴 절차 불필요 | 재다운로드를 주문번호+이메일 조회로 따로 만들어야 함 |
| 회원제 | 재구매·재다운로드 편함, 후속 상품 연결 | 회원약관·탈퇴·휴면계정 처리 전부 추가 |

**권장: 비회원 구매.** 단품 워크북 하나이고 타깃이 10대·20대라 가입 단계에서 이탈이 큽니다.
개인정보 최소 수집 원칙에도 맞습니다. 워크북 시리즈나 커뮤니티 계획이 확정된 뒤에 회원제로 가도 늦지 않습니다.

### ③ 결제 수단

| 선택지 | 특징 |
|---|---|
| **토스페이먼츠 / 포트원(구 아임포트)** | 국내 카드+간편결제 한 번에. 국내 판매면 사실상 표준 |
| 카카오페이·네이버페이 단독 | 연동은 쉽지만 카드 결제를 못 받음 |
| Stripe / Paddle | 해외 판매용. Paddle은 Merchant of Record라 해외 세금을 대신 처리 |
| Gumroad 등 마켓플레이스 | 약관·결제·세금을 플랫폼이 처리 → **가장 빠른 출시 경로** |

> 영문 페이지가 있어 해외 판매를 염두에 두셨다면, 국내(토스페이먼츠)와 해외(Paddle)를 나누는 게
> 세금 처리 면에서 깔끔합니다. 다만 관리 지점이 둘로 늘어납니다.

### ④ 판매 범위

국내만인지, 해외 포함인지. 해외를 포함하면 각국 부가세(VAT/GST) 문제가 생기고,
GDPR 대응(EU 방문자)도 검토 대상이 됩니다.

법정대리인 동의 없는 미성년자의 계약은 **취소할 수 있습니다.**
타깃이 10대라 실제로 발생할 시나리오입니다. 부모 카드로 결제한 뒤 부모가 취소를 요구하면
사업자는 원칙적으로 응해야 합니다.

**대응:** 결제 직전에 "만 19세 미만은 법정대리인 동의가 필요합니다" 고지 + 확인 체크박스.
이걸 두면 분쟁 시 방어 근거가 되고, 두지 않으면 방어가 어렵습니다.

## 3. 환불 정책 — 형태별 구체안

### PDF인 경우 ⚠️ 가장 중요한 지점

전자상거래법 제17조 제6항에 따라, **"다운로드 후 환불 불가"를 유효하게 만들려면 두 가지를 모두** 해야 합니다.

1. 청약철회가 제한된다는 사실을 소비자가 쉽게 알 수 있는 곳에 **명확히 표시**
   (구매 페이지 + 결제 직전 화면 + 주문완료 메일, 세 곳 모두)
2. **시험 사용 상품 제공 등의 조치** — 즉 **미리보기 샘플 PDF를 무료로 제공**

> **둘 중 하나라도 빠지면 그 조항 자체가 무효**가 되어, 다운로드했더라도 7일 내 환불 요구를
> 전부 받아줘야 합니다. 샘플 PDF는 마케팅 선택이 아니라 **환불 정책의 법적 전제조건**입니다.

정리하면:

| 상황 | 처리 |
|---|---|
| 결제 후 **다운로드 전** | 7일 내 전액 환불 |
| **다운로드 후** | 위 1·2 충족 시 환불 제한 가능 |
| 파일 손상·열람 불가 | 정상 파일 재제공, 불가 시 전액 환불 |
| 광고와 내용이 다름 | 3개월/30일 룰 적용 → 환불 |

### 실물인 경우

| 상황 | 처리 | 반품비 |
|---|---|---|
| 배송 전 취소 | 전액 환불 | 없음 |
| 수령 후 7일 내 단순 변심 | 환불 | 소비자 부담 |
| 파본·오배송·하자 | 환불 또는 교환 | 사업자 부담 |
| 사용·훼손으로 재판매 불가 | 제한 가능 | — |

> 내용 확인을 위한 **개봉은 훼손이 아닙니다.** "개봉 시 환불 불가"는 무효입니다.

### 공통

- 환급 기한: **3영업일 이내**. 카드 결제는 승인 취소 요청으로 갈음
- 환불 요청 창구: 이메일(pluspsychology@gmail.com) 단일 창구로 시작해도 충분

## 4. 절차 설계

### 구매 흐름 (비회원 기준)
```
샘플 PDF 열람 (무료)
  → 구매 페이지: 가격·제공방식·청약철회 조건 표시
  → 주문서: 이메일 입력 (실물이면 배송지 추가)
  → 필수 동의 3개
      · 구매조건 확인 및 결제 진행 동의
      · 청약철회 제한 사항 확인 (디지털인 경우)
      · 만 19세 미만은 법정대리인 동의 필요 확인
  → PG 결제창
  → 결제 완료 webhook → 주문 저장 → 다운로드 링크 발급
  → 주문완료 메일 (영수증 + 청약철회 안내 + 다운로드 링크)
```

### 환불 흐름
```
이메일로 요청 접수
  → 주문 조회 (주문번호 또는 결제 이메일)
  → 다운로드 이력 확인 (디지털) / 반품 수령 확인 (실물)
  → 승인 → PG 결제취소 → 3영업일 내 환급
  → 처리 결과 메일 + 사유 기록 보관
```

### 탈퇴 흐름 (회원제를 택한 경우에만)
```
탈퇴 요청 → 본인 확인 → 회원정보 삭제
  → 단, 거래기록은 법정 기간 동안 분리 보관 (삭제 불가)
```

## 5. 개인정보처리방침에 추가해야 할 것

  - 카드번호는 PG사가 직접 수집하며 **사업자는 저장하지 않습니다.** 이 점을 명시
- **위탁·국외이전 표에 PG사 추가** (제5조·제6조)
- **보유기간에 법정 보존 항목 추가** — 탈퇴·수신거부해도 삭제되지 않습니다

## 7. 권장 순서

1. **1장의 네 가지 결정** — 이게 없으면 나머지가 전부 가정이 됩니다
2. 사업자 정보 확정 → `terms.html`·`privacy.html`의 `.todo` 채우기
3. 통신판매업 신고 필요 여부 확인
4. PG사 선정·계약 (심사에 시간이 걸립니다)
5. 샘플 PDF 제작 (디지털인 경우)
6. 구매 페이지 + 결제 백엔드 구현
7. 약관·처리방침 개정 → 판매 개시
