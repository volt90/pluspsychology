# 고요한 숲 배포

- 공개 경로: `https://www.pluspsychology.ai/experience/mind-forest`
- 원본: `https://github.com/volt90/Forest_Interaction`
- 원본 커밋: `7d61c5694a8b76fde0c14cc157e9eec0237d5eea`
- 원본 압축 파일 Git blob: `a14705ee4b71c063ee27af455acf7100c6dccde0`

위 커밋과 ZIP은 최초 가져오기 기준입니다. 현재 `experience/mind-forest.html`은 이후 네 손 동시 추적·후속 영상·모닥불·사진 기능이 추가된 배포본이므로 원본 ZIP으로 덮어쓰지 않습니다. 배포본의 자산은 `01_카메라엔진/`, `02_사람분리모델/`, `03_체험자료/`를 참조합니다. `04_화면과서버/experience/mind-forest.html`은 `/assets/mind-forest/` 경로를 사용하는 보관본이며, 공통 동작 수정은 두 HTML에 함께 반영합니다.

기존 `vercel.json`의 `cleanUrls: true` 설정으로 `.html` 없이 접근합니다. 기존 페이지·도메인 설정·메뉴·사이트맵은 변경하지 않습니다. 이 문서와 자동 검사는 기존 `.vercelignore`에 따라 배포에서 제외됩니다.

## 확인

### Windows 전시 운영 파일

`exhibition/`의 **전시 시작.exe**는 공식 HTTPS 체험 주소를 전시 전용 Chrome 프로필로 열고, **전시 종료.exe**는 그 프로필의 전시 창을 닫습니다. 다른 PC에 Node나 이 개발 폴더를 설치할 필요가 없습니다. 인터넷 연결·Chrome·웹캠과 최초 카메라 권한 허용이 필요합니다. 운영 안내와 재현 가능한 빌드 소스는 [전시 운영 패키지](../exhibition/README.md)를 참고합니다.

새 HTTPS 주소와 빈 브라우저 프로필에서 실제 번들 CPU 손 추적·인물 분리 모델을 합성 영상으로 검증했습니다. 런타임 참조 자산 누락과 외부 CDN 의존은 없으며, 다른 물리 PC의 성능·웹캠·음향은 현장에서 첫 실행 후 확인합니다.

### 손 추적과 모바일 화면 (2026-11-12~13)

- 숲·모닥불·카메라 미리보기에서 같은 좌표 방향을 사용합니다. 공통 좌표 변환 후 기본값으로 좌우 반전하며, `N`키로 반전을 켜고 끕니다.
- 좌표 평활화 계수는 `0.32`, 미세 이동 무시 범위는 정규화 좌표 기준 `0.014`입니다. 중앙 96% 영역을 화면에 대응시켜 직전 88% 설정보다 이동 확대율이 약 8% 낮습니다. 느린 의도적 이동은 누적되어 전달됩니다.
- 검출 신뢰도와 400ms 추적 손실 유예 시간은 유지합니다.
- 폭 620px 이하 세로 화면에서도 카메라 미리보기를 표시합니다. 손 인식 모델을 준비하는 동안에도 연결된 카메라 영상이 먼저 나타납니다.
- 모바일 제목·이름·대사·조작 안내를 축소하고 대사는 상단에 한 번에 하나씩 표시합니다. 음성이 재생 중이면 해당 캐릭터, 음소거 중 대사가 겹치면 가장 최근 캐릭터를 표시합니다. 안내와 카메라 상태 문구는 같은 하단 영역을 번갈아 사용합니다.

### 시작 소리·카메라 (2026-11-13)

2026-11-13 시작 흐름 보완: 첫 화면 자동재생이 제한되면 첫 클릭·키 입력에서 음악을 다시 시작합니다. 안내 음악을 클릭 안에서 미리 활성화하고, 숲에 들어간 뒤에는 낮은 볼륨으로 이어 재생합니다. 소리 버튼과 `M`은 별도 배경음·영상에도 함께 적용하며, `C`와 `M` 등 단축키는 한글 입력 상태에서도 같은 물리 키로 작동합니다.

카메라는 기본 설정과 완화 설정이 실패하면 연결된 다른 영상 장치를 순차적으로 시도합니다. 권한 거부나 사용자의 취소는 재시도하지 않고, 취소 후 도착한 스트림도 즉시 종료합니다. OBS 가상 카메라만 있고 시작할 수 없는 경우에는 OBS/웹캠 연결 안내를 표시합니다.

### 단체 사진 방향과 현장 보정 (2026-11-13)

사진에만 남아 있던 추가 좌우 반전을 제거했습니다. 기본값은 숲·모닥불·사진 모두 좌우 반전이며, `N`키로 공통 방향을 바꿀 수 있습니다. 별도의 방향 전환 버튼 없이 `H` 도움말에 단축키와 현재 방향을 표시합니다. 한글 입력 상태에서도 물리 N키(ㅜ)로 작동합니다. 영상 미리보기·손끝 표시·인물 합성에 함께 적용하며, 사진의 배경·글자는 뒤집지 않습니다. 화면에서 본 인물 방향 그대로 JPEG에 저장합니다.

동일 주소·브라우저에서는 `MediaStreamTrack.getSettings().deviceId`별 선택을 기억합니다. 새 카메라는 기본 방향으로 시작합니다. 저장소 접근이 제한되어도 현재 실행의 장치별 선택은 메모리에서 유지합니다. 방향 변경 시 손 좌표 필터와 핀치 상태를 초기화하고 이전 추론 결과를 버립니다. 촬영 카운트다운과 결과 화면에서는 방향 전환을 잠급니다. 현장 확인 순서는 [카메라 점검 안내](exhibition-camera-check.md)를 참고합니다.

### 캐릭터 고정 음성 (2026-11-13)

루비는 사용자가 선택한 Higgsfield Eleven v4의 Andre 보이스 B 시안을 연결했습니다. 세루는 제공받은 ElevenLabs MP3의 음색을 참고해 기존 인사 대사를 로컬 Qwen3-TTS로 합성했습니다. 원본 MP3에는 해당 인사 문장이 없어 각 인사 대사를 고정 WAV로 연결했습니다. 김심리 사진 초대는 기존에 선택한 김심리 B 음성과 같은 모델·참고 음성 프로필을 사용합니다.

- 루비: `rubi-greeting-v3.wav`, 약 2.43초 — "이 빛, 네가 건넨 거구나."
- 세루: `seru-greeting-v2.wav`, 2.70초 — "따뜻해… 조금만 더 같이 있어 줄래?"
- 사진 초대: `simri-photo-invitation-v2.wav`, 2.05초 — "이제 우리 함께 사진 찍자!"

세 파일은 볼륨 0.72, 약 -19 LUFS로 맞추고 40ms 음량 데이터를 함께 저장했습니다. 김심리 사진 초대는 자동 촬영뿐 아니라 촬영 버튼을 누를 때에도 재생하며 기존 음소거 설정을 따릅니다. 대사와 입 움직임은 고정 파일의 재생 진행을 사용합니다.

루비는 정상 표기 "이 빛, 네가 건넨 거구나."로 생성한 B 시안(stability 0.75, similarity boost 0.75)을 사용합니다. 사용자가 기존 로컬 Qwen 음성의 발음을 지적하고 새 B 시안을 직접 선택했습니다. 승인된 녹음의 말투·피치·타이밍을 유지하며 음량만 맞추고 40ms 입 움직임 데이터를 다시 계산했습니다. Andre는 원본과의 음향 비교로 고른 프리셋이며 Rhuby의 복제본은 아닙니다. 제공받은 원본 녹음을 외부에 업로드하지 않았습니다. [제작·검증 기록](mind-forest-voices.json)에 선택 시안·보이스 ID·설정·파일 해시를 기록했습니다.

### 네 모서리의 모닥불 (2026-11-13)

- 빛은 왼쪽 위 → 오른쪽 위 → 오른쪽 아래 → 왼쪽 아래 순서로 하나씩 나타납니다. 네 빛을 모두 모아야 기존의 두 번째 영상과 사진 장면으로 이어집니다.
- 마우스·터치는 현재 코너의 빛을 누른 채 중앙으로 끌어 놓습니다. 웹캠은 손 아이콘을 현재 빛에 맞추고 엄지·검지를 펴서 오므리면 빛이 자동으로 모닥불에 날아갑니다. 아이콘도 핀치 모양으로 바뀝니다.
- MediaPipe의 엄지 끝(4)·검지 끝(8) 간격을 영상 비율과 손바닥 크기로 보정합니다. 비율 `0.30` 이하를 90ms 유지해야 핀치로 인식하고 `0.48` 이상 벌려야 다시 집을 수 있습니다. 위치가 정지해 있어도 제스처는 전달하며, 처음부터 닫힌 손·추적 유실·오래된 결과는 새 핀치로 사용하지 않습니다.
- 빛을 전달할 때마다 불이 커지고, 잠시 뒤 다음 코너가 활성화됩니다. 중앙에 계속 머무는 동작으로 여러 빛을 한꺼번에 모을 수 없습니다.
- 키보드는 Tab으로 모닥불 버튼에 초점을 둔 뒤 Enter 또는 Space를 네 번 따로 누릅니다. 키를 길게 눌러도 한 번만 반영됩니다. 키보드 안내는 해당 버튼에 키보드 초점이 있을 때만 표시합니다.
- 네 번째 불의 최대 크기를 보여 준 뒤 다음 장면으로 전환합니다. 처음으로 돌아가거나 장면을 떠나면 진행 중인 전달과 예약된 전환을 취소합니다.
- 완료 문구는 인원수와 관계없이 "많은 빛이 모여, 더 따뜻해졌어요."로 표시합니다.

### 영상 전환과 재촬영 (2026-11-13)

1·2부 영상으로 넘어갈 때 제목 카드를 표시하지 않습니다. 영상 제목은 스크린리더용으로만 유지하고, 사진 서비스 설정은 숲 시작 시 미리 조회합니다. 준비된 설정이 있으면 지정된 영상을 사용하고, 아직 응답이 없으면 번들 영상을 즉시 재생합니다. 사진 설정 API를 기다리느라 영상 전환이 늦어지지 않습니다. 영상 자체를 열 수 없을 때만 간단한 오류 안내 후 다음 장면으로 이어갑니다.

사진 결과 화면의 **다시 찍기** 버튼은 숲을 다시 진행하지 않고 카메라 미리보기로 돌아갑니다. 이전 자동 복귀·자동 촬영 타이머와 로컬 다운로드 URL·QR을 정리하고 촬영 흐름 버전을 갱신해 이전 비동기 작업이 새 화면을 덮지 않게 합니다. 재촬영에도 기존 준비 시간과 촬영 카운트다운을 사용하며, 새 결과에 새 다운로드·QR을 연결합니다. H 도움말을 보는 동안 준비 화면의 자동 촬영은 대기하고 닫으면 다시 예약합니다.

### 단체 사진 배경 분리 실패 처리 (2026-11-13)

인물 분리 모델이 준비되지 않거나 오류가 나면 초록색만 지우는 방식으로 바뀌던 동작을 제거했습니다. 일반 벽이나 가구가 원본 카메라 화면과 함께 합성될 수 있었기 때문입니다. 모델 초기화는 최대 30초, 한 프레임 처리는 최대 5초까지 기다리며 유효한 인물 마스크가 있어야 미리보기와 촬영을 진행합니다. 실패하면 이전 인물 레이어와 자동 촬영 예약을 지우고, 단체 사진 찍기 버튼으로 재시도할 수 있게 합니다.

7초의 모델 로딩 지연으로 기존 배경 노출을 재현했고, 수정본에서는 실제 MediaPipe 모델로 네 사람이 있는 시험 이미지의 얼굴을 모두 유지하고 상단 배경을 제거했습니다. 미리보기와 촬영 결과의 일치, 강제 모델 오류 후 원본 배경 미노출과 재시도 버튼도 확인했습니다. 시험 사진은 외부 저장소로 전송하지 않았습니다.

### 웹사이트에 저장하는 사진 QR (2026-11-13)

사진은 기존 웹사이트의 `api/mind-forest-photo.js`를 통해 같은 Supabase 프로젝트의 비공개 Storage 버킷 `mind-forest-photos`에 JPEG로 저장합니다. 데이터베이스에 이미지 문자열을 넣는 대신 Supabase의 파일 저장소를 사용합니다. `SUPABASE_URL`과 `SUPABASE_SERVICE_ROLE_KEY`는 운영 서버의 기존 환경변수를 사용하며 브라우저와 로컬 미리보기에는 전달하지 않습니다.

QR은 항상 `https://www.pluspsychology.ai/api/mind-forest-photo?photo=…`를 가리킵니다. 휴대폰은 모바일 데이터나 다른 Wi-Fi에서도 열 수 있고 촬영 PC가 꺼져도 유효 시간 안에는 다운로드할 수 있습니다. 기존 10분의 링크 유효 시간은 유지합니다. 만료 사진은 이후 업로드 또는 예약 정리 작업 때 저장소에서 제거합니다.

로컬 실행은 저장소에서 `npm run dev:mind-forest`를 실행한 뒤 `http://127.0.0.1:8765/experience/mind-forest.html`을 엽니다. 이 서버는 사진 요청을 고정된 공식 웹사이트 API로 중계합니다. 로컬 사진 보관과 LAN 주소 QR은 사용하지 않으며 촬영 PC에는 인터넷 연결이 필요합니다. 단순 정적 서버나 HTML 파일 직접 열기는 사진 업로드를 지원하지 않습니다.

설정 조회가 일시적으로 실패해도 최종 사진 업로드는 다시 시도합니다. 업로드가 실패하면 QR 대신 실패 안내와 기기 저장 버튼을 표시합니다. 실제 사진을 찍으면 운영 저장소에 업로드되므로 자동 검사는 합성 사진과 모의 저장소 응답을 사용합니다.

### 자동 검사

```powershell
node --test tests/forest/*.test.cjs
node --test tests/bgm-qr.test.cjs
node --test tests/mind-forest-photo.test.cjs tests/forest-photo-dev-server.test.cjs
```

배포한 URL에서 시작 인사 → 조작 안내 → 시작하기, 카메라 허용/거부, 소리를 켠 상태의 네 캐릭터 반응, 손 이탈/복귀, 카메라 종료를 확인합니다. 카메라는 시작 버튼 뒤에 요청하며, 첫 화면 음악은 브라우저 자동재생 정책에 따라 첫 입력을 기다릴 수 있습니다.

원본을 다시 가져올 때에는 이 문서의 원본 커밋을 갱신하고 자산과 HTML을 함께 교체해야 합니다. ZIP 파일 자체를 정적 경로에 올리는 것으로는 체험 화면이 배포되지 않습니다.
