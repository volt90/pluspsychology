# 현장에서 카메라 좌우 방향 확인하기

## 카메라 미리보기가 안 나올 때

- 홈페이지와 `전시 시작.exe`는 같은 HTTPS 체험을 엽니다. 카메라 테스트는 두 창 중 하나만 열고 진행합니다. Zoom·OBS·Windows 카메라 등 같은 웹캠을 쓰는 앱도 닫습니다.
- 전시 실행 파일은 별도 Chrome 프로필을 사용합니다. 홈페이지에서 이미 허용했어도 전시 창에서 카메라 사용을 한 번 더 허용해야 할 수 있습니다.
- 시작하면 먼저 카메라 미리보기가 나타나고, 손 인식 파일을 준비하는 동안에도 영상이 보입니다. 세로 화면에서도 미리보기를 숨기지 않습니다.
- 20초 동안 권한이나 장치가 응답하지 않으면 재시도 안내가 나옵니다. 권한 창을 확인한 뒤 **카메라 켜기**를 누릅니다. 만료된 요청에 뒤늦게 연결된 카메라는 자동으로 해제합니다.
- **카메라는 연결됐지만 영상이 들어오지 않아요**는 영상 재생 문제이고, **카메라 영상은 연결됐지만 손 인식을 준비하지 못했어요**는 손 인식 준비 문제입니다. 표시되는 문구를 구분해 확인합니다.

## 좌우 방향 점검

1. 체험을 열고 카메라를 켭니다. 기본값은 거울처럼 좌우 반전된 방향입니다. 로컬 실행 주소는 `http://127.0.0.1:8765/experience/mind-forest.html`입니다.
2. 관객 자리에 서서 손을 본인 기준 오른쪽으로 움직입니다. 화면의 빛도 오른쪽으로 움직이는지 확인합니다.
3. 반대로 움직이면 **N키**를 한 번 누릅니다. 숲·모닥불·카메라 미리보기·단체 사진에 같은 설정이 적용됩니다. 한글 입력 상태에서도 같은 물리 N키(ㅜ)를 쓸 수 있습니다. **H키**로 여는 도움말에 단축키 안내와 현재 방향이 표시됩니다.
4. 단체 사진 미리보기에서도 같은 방향인지 확인하고 필요하면 N키로 바꿉니다. 촬영 카운트다운이 시작되면 방향을 고정하고, 저장 사진도 미리보기와 같은 방향으로 만듭니다. 배경 글자와 캐릭터는 뒤집지 않습니다.

같은 주소·브라우저에서는 카메라 장치별 선택을 기억합니다. 새 카메라나 다른 브라우저에서는 다시 확인합니다. 장치 식별자를 받지 못하거나 저장을 사용할 수 없는 환경에서도 현재 실행 중에는 방향을 바꿀 수 있습니다.

## 웹캠 설정인지 확인하려면

이번 문제는 사진 합성 코드에만 있던 추가 좌우 반전 때문에 생겼습니다. 이것만으로 웹캠 자체가 특이하게 설정됐다고 판단할 수는 없습니다.

Windows 11에서는 **설정 → Bluetooth 및 장치 → 카메라 → 연결한 카메라**에서 해당 장치의 미리보기와 지원 설정을 확인할 수 있습니다. 제조사 앱을 사용하는 경우 그 앱의 Mirror / Horizontal Flip / 좌우 반전 항목도 확인합니다. 지원 항목은 카메라마다 다르고, 앱이 별도 설정을 적용할 수 있으므로 최종 판단은 실제 체험 화면에서 움직여 보고 합니다. 현장 점검을 위해 기존 드라이버 설정 전체를 초기화할 필요는 없습니다.
