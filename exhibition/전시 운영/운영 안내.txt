김심리월드 · 전시 운영

전시 시작.exe : 전용 Chrome 창으로 전시를 엽니다.
전시 종료.exe : 전시용 Chrome 창만 닫습니다. 평소 사용하던 Chrome은 유지됩니다.

운영 주소
https://www.pluspsychology.ai/experience/mind-forest

다른 컴퓨터로 가져가기
1. 이 '전시 운영' 폴더를 통째로 복사합니다. 폴더 이름이나 위치를 바꿔도 됩니다.
2. Windows 10/11에 최신 Google Chrome을 설치하고 인터넷을 연결합니다.
3. USB 웹캠을 연결한 뒤 '전시 시작'을 실행합니다.
4. 새 컴퓨터에서는 처음 한 번 Chrome의 카메라 접근을 허용합니다.
5. 첫 화면에서 숲으로 들어가 손 움직임과 소리를 확인합니다.

현장 조작
N : 웹캠 좌우 방향 전환 (한글 입력 상태에서도 같은 위치의 키)
H : 도움말 열기·닫기
C : 숲·모닥불에서 카메라 켜기·끄기
M : 소리 켜기·끄기
사진 결과의 '다시 찍기' : 바로 재촬영
Alt+Tab 또는 Windows 키 : 바탕화면으로 전환 후 '전시 종료' 실행
Alt+F4 : 현재 전시 창 직접 닫기

카메라 방향은 카메라 장치별로 기억합니다. 웹캠이나 컴퓨터가 바뀌면 다시 확인하세요.
카운트다운 중에는 방향을 바꿀 수 없습니다. 촬영 후 '다시 찍기'를 누르고 N키로 맞춥니다.
카메라가 켜지지 않으면 Zoom·OBS 등 다른 앱의 사용 여부와 Windows의 카메라 개인정보 설정을 확인하세요.
새 웹캠의 실제 영상·조명·설치 각도는 설치 현장에서 확인해야 합니다.

인터넷과 사진 QR
인터넷 연결이 필요합니다. 사진 QR은 공식 웹사이트를 이용하므로 휴대폰은 다른 Wi-Fi나 모바일 데이터를 써도 됩니다.
사진은 약 10분 뒤 만료됩니다. 카메라 권한을 자동으로 허용하거나 Windows 보안 설정을 변경하지 않습니다.
본 실행 파일은 Windows용이며 Mac에서는 Chrome에서 운영 주소를 직접 열어 주세요.

첫 실행 안내
새로 만든 실행 파일은 코드 서명이 없어 Windows/보안 프로그램의 확인 화면이 나타날 수 있습니다.
회사·전시장 관리 PC에서 실행을 차단하면 담당 관리자에게 이 폴더와 GitHub의 소스를 전달해 확인받으세요.
실행 프로그램은 개인 Chrome 프로필을 쓰지 않고 아래 전시 전용 프로필을 사용합니다.
%LOCALAPPDATA%\PlusPsychology\MindForestExhibition\ChromeProfile
폴더를 복사할 때 이 프로필까지 다른 컴퓨터에 복사할 필요는 없습니다.
